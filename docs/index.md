Welcome to VettCode — one ecosystem for turning ideas into real software. From your first prompt to production, VettCode gives you the tools to create, code, test, secure, and deploy applications.

## VettCode Ecosystem

### VettCode Vibe

Turn ideas into applications. Describe what you want to build and work with AI to create websites, applications, and digital products.

### VettCode Vibe CLI

Your AI coding agent in the terminal. Build directly inside your development environment with AI assistance.

### VettCode CLI

Don't just build it. Know it's safe. Scan your projects for security vulnerabilities, exposed secrets, dependency risks, and other problems.

### VettCode Web

AI-powered security analysis dashboard. Upload scan results, get intelligent explanations, and learn security best practices.

### VettCode Web Host

Take your creation to the world. Deploy your application through the VettCode ecosystem.

## Key Features

### Security Scanning

- **Static Analysis** - Find vulnerabilities in your code
- **Secret Detection** - Never accidentally commit secrets
- **Dependency Scanning** - Check for vulnerable dependencies
- **AI Explanations** - Understand security issues in plain language

### AI-Powered Analysis

- Multiple AI providers for reliability
- Subscription-aware routing

- Comprehensive reporting
